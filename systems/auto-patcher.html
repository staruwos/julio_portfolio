Auto Patcher C++ Qt Launcher

A custom game updater with integrity verification and a frameless desktop interface.

Project Overview

Auto Patcher downloads and installs game updates, verifies files with SHA-256, and extracts ZIP packages without external dependencies. The launcher uses Qt Widgets and a custom non-rectangular window design.

Technology

C++17 · Qt Widgets · QNetworkAccessManager · SSL · Miniz
