Blastcomp M68K Toolchain

A Docker container for cross-compiling C programs for Sega Genesis and Mega Drive hardware.

BLASTCOMP_CONTAINER

Project Overview

Blastcomp packages the M68K compiler workflow in a reproducible Docker environment. A typical build produces a Genesis ROM from a C source file using the cross-compiler inside the container.

Build Example

make build -> m68k-gcc main.c -o rom.bin
