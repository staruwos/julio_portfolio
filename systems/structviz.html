Structviz C Memory Visualizer

An interactive tool for understanding C struct padding and alignment.

STRUCTVIZ

Project Overview

Structviz parses C declarations and calculates memory layouts across LP64, LLP64, ILP32, and 8-bit cc65 architectures. It helps developers inspect alignment costs and wasted space interactively.
