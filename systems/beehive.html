Beehive MQTT Telemetry Pipeline

A distributed telemetry architecture for embedded nodes and web-based monitoring.

BEEHIVE

Project Overview

Beehive connects a swarm of embedded nodes through MQTT, ingests high-frequency telemetry with a Python service, and exposes the data to a web visualizer. The target deployment is Raspberry Pi running an embedded Linux stack.

Technology

Yocto · Mosquitto · MQTT · Python · Raspberry Pi
