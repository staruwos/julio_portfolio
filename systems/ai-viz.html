3D Game AI Visualizer

An interactive playground for understanding pathfinding and game-AI behaviors.

AI_VIZ

Project Overview

AI Viz is a 3D pathfinding playground built to compare algorithms like A*, Dijkstra, and Greedy Best-First Search in real-time. It features interactive obstacle placement, real-time rendering, and simulated game-AI behaviors such as patrolling and wandering.

Technology

HTML5 · CSS3 · Vanilla JavaScript · Three.js
