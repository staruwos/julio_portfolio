Binary Depression

A feature-rich C++ terminal interface and environmental manipulation system built for the Epic AI Mega Jam.

BINARY_DEPRESSION.EXE

Project Overview

Developed for the Epic AI Mega Jam, Binary Depression puts the player in control of a deep-facility command terminal. The system combines a modular C++ backend component (`TerminalComponent`) with Unreal Engine Blueprints to allow complex interaction with world physics, device networks, and an autonomous AI companion.

Key features include global gravity/time controls, dynamic multi-property batch object adjustments, physical 3D Zero-G EVA flight mechanics, and an unpredictable terminal trickster named "Term".

Core Systems & Tech Stack

  • C++ Terminal Parser: Custom command router supporting arguments, flags, and `sudo` privilege overrides.
  • World Environment Control: Real-time toggles for gravity vectoring, time dilation, and cached lighting grids.
  • Device Network: Persistent `TMultiMap` registry supporting grouped multi-actor interactions via Actor Tags and Interfaces.
  • Zero-G EVA Movement: Custom character movement mode switching between ground walking and 3D camera-relative space flight.
