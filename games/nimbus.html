Project Overview

A zero-asset procedural 3D gameplay prototype inspired by classic Dragon Ball. Built completely from primitives and custom shaders, featuring a 26-sphere volumetric breathing Nimbus cloud, pooled turbulent cloud trail particles, ribbon speed streaks, and 3-band Akira Toriyama cel-shading with screen-space compensated inverted-hull outlines.

Technology

Three.js · WebGL · GLSL Shaders · JavaScript · Web Audio API
